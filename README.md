# Servants de Messe — Frontend (Vue 3)

    npm install
    npm run dev

- Données simulées dans `src/services/mock.js` ; passer `USE_MOCK` à `false` dans `src/services/api.js` pour utiliser l'API Express (`VITE_API_URL`).
- Comptes de démonstration : `admin` / `admin` (admin global), `dome` / `dome` (responsable Dôme).
- Les images publiques sont des visuels libres de démonstration stockés dans `public/images`; ne pas les associer à des personnes réelles sans validation des règles RG12/RG13.
- Images de démonstration issues d’Unsplash : [Josh Applegate](https://unsplash.com/@joshapplegate), [Clay Banks](https://unsplash.com/@claybanks), [Jonathan Dick](https://unsplash.com/@jondick91), [Juliana Tanchak](https://unsplash.com/@radio_jane) et [Roger Starnes Sr](https://unsplash.com/@rstar50).
